🏀 Tutorial BASIK: Membuat Animasi Bola Memantul (Bouncing Ball)

Pada tutorial ini, kita akan belajar cara membuat animasi pergerakan bola yang dapat memantul secara otomatis ketika menabrak batas dinding kanvas. Proyek ini merupakan fondasi penting sebelum membuat gim interaktif yang lebih kompleks seperti Pong, Breakout, atau Pinball.

💡 Konsep Dasar yang Perlu Dipahami

Sebelum masuk ke baris kode, mari pahami tiga konsep utama yang digunakan dalam proyek ini:

  1. Sumbu Koordinat Kanvas BASIK:
    • Secara bawaan (default), kanvas BASIK memiliki ukuran 800 x 600 piksel.
    • Titik (0, 0) terletak di sudut kiri atas kanvas.
    • Nilai Sumbu X bertambah jika bergerak ke kanan.
    • Nilai Sumbu Y bertambah jika bergerak ke bawah.
  2. Vektor Kecepatan (vx dan vy):
    • vx (Velocity X) menentukan kecepatan gerak mendatar (horisontal). Nilai positif bergerak ke kanan, nilai negatif bergerak ke kiri.
    • vy (Velocity Y) menentukan kecepatan gerak tegak (vertikal). Nilai positif bergerak ke bawah, nilai negatif bergerak ke atas.
  3. Prinsip Animasi Komputer (Flipbook):
    • Animasi bekerja seperti buku gambar lipat. Di setiap frame (bingkai), layar dibersihkan, posisi objek digeser, dan objek digambar kembali di posisi yang baru.

📜 Kode Program Lengkap

Berikut adalah kode lengkap yang akan kita bahas:


  mulai();

  let bola = muatGambar("bola");
  pusatGambar(bola, 32, 32);
  let vx = 3;
  let vy = 4;

  function update() {
    geserGambar(bola, vx, vy);

    if (bola.x > 768) {
      bola.x = 768;
      vx = -3;
    }

    if (bola.x < 32) {
      bola.x = 32;
      vx = 3;
    }

    if (bola.y < 32) {
      bola.y = 32;
      vy = 4;
    }

    if (bola.y > 568) {
      bola.y = 568;
      vy = -4;
    }

    bl();
    stempel(bola);
  }

🔍 Bedah Kode Langkah demi Langkah

Mari kita dekonstruksi kode di atas menjadi beberapa bagian logis:

1. Inisialisasi Aplikasi dan Memuat Objek Gambar

mulai();

let bola = muatGambar("bola");
pusatGambar(bola, 32, 32);
  • mulai();: Perintah awal untuk mengaktifkan aplikasi dan menyiapkan kanvas BASIK berukuran 800 x 600 piksel. Ini adalah perintah pertama yang harus dipanggil untuk memulai aplikasi yang dibuat dengan BASIK.
  • let bola = muatGambar("bola");: Memuat berkas gambar bernama "bola" dari folder aset dan menyimpannya ke dalam variabel bola sebagai sebuah objek gambar. Dengan menjadi objek, kita bisa membaca dan mengubah properti seperti posisi bola.x dan bola.y.
  • pusatGambar(bola, 32, 32);: Mengatur titik pusat (anchor point) gambar bola. Jika gambar bola berukuran (64 x 64) piksel, titik tengahnya berada di jari-jari 32 piksel dari tepi. Pengaturan ini memudahkan perhitungan batas dinding.

2. Menentukan Kecepatan dan Arah Awal

let vx = 3;
let vy = 4;
  • vx = 3;: Menandakan bola bergerak ke kanan sebanyak 3 piksel per frame.
  • vy = 4;: Menandakan bola bergerak ke bawah sebanyak 4 piksel per frame.
  • Karena vx dan vy aktif bersamaan, bola akan bergerak secara diagonal ke arah kanan-bawah.

3. Menggerakkan Bola di Dalam Loop update()

function update() {
	geserGambar(bola, vx, vy);
  • function update(): Fungsi utama BASIK yang dijalankan secara berulang-ulang puluhan kali per detik (loop animasi utama).
  • geserGambar(bola, vx, vy);: Mengubah koordinat posisi objek bola secara berkesinambungan dengan menambahkan nilai vx ke bola.x dan vy ke bola.y.

4. Logika Pantulan Dinding (Deteksi Batas / Collision Detection)

Bagian pengondisian if ini menggunakan pilar abstraksi dan algoritma untuk mendeteksi empat batas dinding kanvas:

A. Pantulan Dinding Kanan (bola.x > 768)

if (bola.x > 768) {
  bola.x = 768;
  vx = -3;
}
  • Lebar kanvas adalah 800 piksel. Karena titik pusat bola berada di tengah (jari-jari 32 piksel), tepi kanan bola akan menyentuh batas saat posisi X = 800 - 32 = 768.
  • bola.x = 768;: Menahan bola agar tidak menembus keluar dari kanvas.
  • vx = -3;: Mengubah arah pergerakan horisontal menjadi negatif (bergerak ke kiri).

B. Pantulan Dinding Kiri (bola.x < 32)

if (bola.x < 32) {
  bola.x = 32;
  vx = 3;
}
  • Batas kiri kanvas adalah X = 0. Tepi kiri bola menyentuh dinding saat titik pusatnya berada di 0 + 32 = 32.
  • bola.x = 32;: Menahan posisi bola tepat di tepi kiri.
  • vx = 3;: Membalikkan arah gerak menjadi positif (kembali bergerak ke kanan).

C. Pantulan Dinding Atas (bola.y < 32)

if (bola.y < 32) {
  bola.y = 32;
  vy = 4;
}
  • Batas atas kanvas adalah Y = 0.
  • bola.y = 32;: Menahan posisi bola di batas atas.
  • vy = 4;: Membalikkan arah gerak vertikal menjadi positif (bergerak ke bawah).

D. Pantulan Dinding Bawah (bola.y > 568)

if (bola.y > 568) {
  bola.y = 568;
  vy = -4;
}
  • Tinggi kanvas adalah 600 piksel. Tepi bawah bola menyentuh dasar kanvas saat Y = 600 - 32 = 568.
  • bola.y = 568;: Menahan bola agar tidak membal melampaui batas bawah.
  • vy = -4;: Membalikkan arah gerak vertikal menjadi negatif (kembali memantul ke atas).

5. Membersihkan dan Merender Layar

	bl();
	stempel(bola);
}
  • bl();: Singkatan dari bersihkanLayar(). Fungsi ini menghapus gambar bola dari frame sebelumnya. Tanpa baris ini, bola akan meninggalkan jejak garis tebal di sepanjang lintasannya.
  • stempel(bola);: Menampilkan ulang visual objek bola pada lokasi koordinat barunya.

🛠️ Ringkasan Fungsi BASIK yang Digunakan

Perintah BASIK Kegunaan / Fungsi Utama Keterangan Parameter
mulai() Menginisialisasi kanvas dan aplikasi BASIK Ukuran default: 800 x 600 piksel
muatGambar(url) Memuat gambar dari folder aset menjadi objek Mengembalikan objek Gambar
pusatGambar(gbr, x, y) Menentukan titik acuan/pusat objek gambar x dan y adalah jarak titik pusat dari sudut kiri atas gambar
geserGambar(gbr, x, y) Menggerakkan posisi objek secara relatif Menambahkan x ke gbr.x dan y ke gbr.y
bl() / bersihkanLayar() Membersihkan jejak visual di kanvas Mencegah terjadinya glitch atau efek bayangan berjejak
stempel(gbr) Menggambar/merender objek ke layar Menampilkan objek sesuai koordinat terbarunya

❓ Menganalisis & Mengatasi Masalah (Debugging Guide)

Dalam belajar koding, error atau perilaku aneh adalah bagian normal yang melatih pemikiran kritis:

  1. Bola meninggalkan jejak panjang seperti ekor komet:

    • Penyebab: Kamu lupa memanggil fungsi bl(); di dalam fungsi update().
    • Solusi: Pastikan bl(); dipanggil sebelum stempel(bola);.

  2. Bola bergetar atau tersangkut di dinding:

    • Penyebab: Lupa menyertakan perintah reset posisi (bola.x = 768;, dll.) saat pengondisian if. Jika posisi tidak direset, bola masih berada di luar batas pada frame berikutnya sehingga arah kecepatan terus-menerus berbalik bolak-balik.

  3. Bola tidak muncul di layar sama sekali:

    • Penyebab: Nama berkas gambar di muatGambar("bola") tidak cocok dengan berkas di folder aset, atau lupa memanggil stempel(bola); di akhir fungsi update().

🚀 Latihan Tantangan Mandiri (Hands-On Challenge)

Uji pemahamanmu dengan memodifikasi kode di atas:

  • Tantangan 1 (Kecepatan Tinggi): Ubah nilai vx menjadi 8 dan vy menjadi 12. Apa yang terjadi pada gerak bola?
  • Tantangan 2 (Efek Gravitasi): Tambahkan baris kode vy = vy + 0.2; tepat di atas geserGambar(bola, vx, vy); di dalam fungsi update(). Amati bagaimana bola akan jatuh semakin cepat dan memantul layaknya bola basket sungguhan!
  • Tantangan 3 (Pengacak Sudut Pantul): Cobalah ubah nilai vx = -3; saat memantul di dinding kanan menjadi angka acak antara -2 sampai -6 agar arah pantulan sulit ditebak!
