📖 Interaksi

Pada tulisan sebelumnya kita sudah belajar cara memuat gambar dan menyetempelkannya ke layar.

Di tulisan kali ini kita akan membahas tentang interaksi.

BASIK mendukung banyak sekali interaksi, salah satunya adalah interaksi saat mouse digerakkan.

mulai();
let roket = muatGambar("roket");

function mouseGerak() {
	stempel(roket, mouseX(), mouseY());
}

Bila kode di atas dijalankan, dan kita menggerakkan mouse, maka akan terlihat gambar roket di layar yang terus di gambar mengikuti posisi mouse.

Fungsi mouseGerak() adalah fungsi yang menangani saat mouse digerakkan. Di dalam fungsi ini kita memiliki satu perintah, yaitu perintah stempel(): yang akan menyetempel gambar roket.

📖 Memuat Gambar

Pada tulisan sebelumnya kita sudah belajar cara menyetempel gambar ke layar.

Pada tulisan kali ini kia akan membahas bagaimana caranya untuk memuat gambar terlebih dahulu sebelum menyetempelnya ke layar.

Perhatikan kode berikut:

mulai();
let roket = muatGambar("roket");
stempel(roket);

muatGambar() adalah perintah untuk memuat gambar, di contoh ini kita memuat gambar “roket”, menyimpannya ke variable roket, kemudian menyetempelkan ke layar dengan perintah stempel().

Perhatikan disini kita menggunakan variable roket sebagai parameter perintah stempel() dan tidak menggunakan nama file: “stempel”;

📖 Memulai BASIK

Untuk pengguna daring, BASIK bisa dibuka melalui alamat ini.

Untuk pengguna luring, silakan download dahulu, kemudian ekstrak dan buka file basik.html di browser untuk memulai.

Contoh aplikasi sederhana:

mulai();
stempel("roket");

mulai() adalah perintah pertama yang berfungsi untuk memulai aplikasi. Perintah ini harus dipanggil pertama kali sebelum memanggil perintah yang lain.

stempel("roket") adalah perintah untuk men-stempel gambar ke kanvas. “roket” adalah gambar yang ingin distempel.

Tekan tombol Jalankan untuk menjalankan aplikasi. Kita akan melihat gambar roket di pojok kiri atas layar.

📖 fungsi Update

Fungsi update adalah fungsi bawaan dari BASIK untuk menangani apa yang terjadi saat applikasi di update. Perhatikan contoh berikut:

mulai();
let astro = muatGambar('astronot');
posisiGambar(astro, 400, 300);

function update() {
	bl();
	putarGambar(astro, 5);
	stempel(astro);
}

Jalankan aplikasi ini maka akan terlihat di layar gambar astronot yang berputar tanpa henti.

BASIK akan di update secara terus menerus, dan setiap kali update terjadi maka semua perintah yang ada di dalam fungsi update() akan terus dijalankan.
